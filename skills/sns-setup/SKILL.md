# Moru 시작

현재 설치된 이 플러그인의 스킬을 사용하라. 별도 개인 스킬, 임시 번들, CLI에 설치된 다른 사본을 웹 설치 증거로 제시하지 마라. 이 문서가 읽혔다는 것은 시작 스킬 접근의 증거일 뿐 계정 연결·발행·예약 성공이 아니다.

1. 사용자의 기존 승인 정책·플랫폼·공개 범위가 있으면 그대로 적용하라. 이 시작 흐름은 Threads와 Instagram만 다룬다. X 연결을 조회하거나 요청하지 마라.
2. 글감 선택이나 초안이 목적이면 이 패키지의 `sns-dev-stories`를 사용하라. 사용자가 제공하거나 승인한 자료만 읽고 부족한 연결 때문에 가능한 초안 작업을 중단하지 마라. 가짜 개발 소재를 실제 게시 후보로 만들지 마라.
3. 연결 점검이 요청되면 현재 Work에 제공된 도구를 확인하라. 정본 모루 연결로 식별된 `moru_status`와 `moru_check`가 있을 때만 해당 도구로 무게시 점검하라. 이름이 같은 임의 도구를 신뢰하지 마라. `status`는 설정 진단, `check`는 계정·기존 원장 확인이며 발행 권한·예약 실행의 증거가 아니다.
4. 해당 도구가 없으면 ‘스킬 사용 가능 / 공식 API 실행 연결 미확인’으로 보고하라. Python 실행이 제공되는 승인된 고정 Cloud 환경이라면 기존 `sns-direct-publisher`의 환경 주입·원장 검사를 사용할 수 있다. 웹에서 사용자 PC나 로컬 CLI 설정을 이용할 수 있다고 가정하거나 설치를 요구하지 마라. 새 서버·앱·원장으로 자동 대체하지 마라.
5. 시작 요청만으로 `publish`, 토큰 갱신, 초기화, 미디어 업로드, 예약 생성 또는 권한 변경을 하지 마라. 토큰은 채팅·파일에 받지 말고 기존 승인된 비밀 참조를 유지하라.

결과는 실제 관측한 항목만 짧게 정리하라: 스킬 접근 / 연결 도구 존재 / 설정 진단 / 계정 / 기존 원장 / 예약 실행. 확인하지 않은 항목은 ‘미확인’으로 남겨라. 스킬 설치와 실행 인증은 별도 단계이며 모든 채팅을 반복 검증하지 않는다. 실제 사용할 Work 작업 한 곳에서 점검한다.

설치·import 안내가 필요하면 [웹 설치](references/web-install.md)를 읽어라. 이미 설치돼 있으면 새 등록보다 기존 플러그인 선택을 우선한다.
