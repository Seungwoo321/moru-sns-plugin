# DF-001: 주입된 인증을 private wrapper가 읽지 못함

대상 변경: 패키지 0.1.0 → 0.1.1. 배포 여부는 저장소의 병합 상태와 배포 manifest로 확인한다.

## 재현

0.1.0의 `private_runtime.py doctor --connection threads`는 종료 코드 2와 일반 인자 오류를 반환한다. `run`도 외부 `--config`를 필수로 요구해, 이미 환경변수로 주입된 자격증명을 파일로 복제하지 않고 사용할 경로가 없다. 빈 환경변수 예시에는 예상 username과 Instagram 로그인 모드가 빠져 있었다.

## 수정

- `doctor --connection`으로 값 없는 로컬 설정 진단을 제공한다.
- `run --connection`은 현재 프로세스 환경만 읽는다. 외부 `--config`와 혼용하지 않는다.
- `run check`는 공식 API의 예상 ID와 username을 함께 대조한다.
- 상태 guard가 같은 환경 연결을 읽도록 하되 기존 marker·원장·파일 권한 검사를 유지한다.
- OAuth 최초 취득, 보관된 토큰 사용, 외부 파일 전용 갱신을 문서에서 구분한다.

## 검증

패키지 검사와 합성 토큰·가짜 API를 사용하는 회귀 검사 93개 통과. 추가 검사는 누락/잘못된 키 이름만 출력, username 불일치 차단, 자식 환경에만 토큰 전달, 미존재 원장의 publish/metrics 사전 차단, 파일/환경 혼용 거절, Instagram 모드 필수, 기존 원장 무변경을 확인한다.

운영 설치는 공식 GitHub 저장소의 배포본만 사용한다. doctor는 네트워크 0건이며 계정 인증·권한·영속성·예약 성공의 증거가 아니다. PR 개발본이나 별도 개인 스킬을 공식 배포본 대신 운영하지 않는다.

검사 환경의 샌드박스는 `/tmp`에 `.git` 보호 표식을 노출해 기존 테스트의 비공개 경로 가드를 차단했다. 제품 가드를 변경하지 않았고, 승인된 샌드박스 밖 오프라인 검사에서 전체 통과를 확인했다. 표식 삭제나 운영 원장 재생성은 하지 않았다.

## 남은 운영 조건

공식 호스트 접근, 실제 계정 권한, 기존 정식 원장 연결, 운영 세션에 귀속된 무인 실행은 별도로 검증해야 한다. 누락된 환경변수만으로 Vault 토큰 부재·만료를 판정하지 않는다. 이 수정은 새 앱·원장·스케줄러·공개 게시를 만들지 않는다.
